\begin{abstract}
WebAssembly (Wasm) is a secure, efficient, and portable binary instruction format designed for high-performance execution across diverse computing environments.
As Wasm evolves with new features such as SIMD, garbage collection, and exception handling, ensuring conformance with its formal specification becomes increasingly complex.
Rigorous testing is essential to validate Wasm implementations and uncover inconsistencies.

In this work, we introduce WEST (Wasm Test), a novel framework that leverages SpecTec, a mechanized specification framework for Wasm, to automate the generation of semantically rich and specification-compliant test cases.
By systematically deriving tests from the formal specification, WEST enables comprehensive validation of Wasm engines, adapting to the language’s rapid evolution.
Our approach not only facilitates the generation of correct and diverse test cases but also serves as a tool for detecting inconsistencies in the Wasm specification itself.
Using WEST, we developed an automated test generator for Wasm 3.0, uncovering 42 previously unknown bugs in existing implementations.
Our results demonstrate the effectiveness of WEST in improving the robustness of Wasm engines, contributing to the advancement of automated testing in the Wasm ecosystem.
\end{abstract}
